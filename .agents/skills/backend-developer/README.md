# Backend Developer Agent Skill

A portable Agent Skills-format skill for Flask/Python backend development.

## Contents
- `SKILL.md`: skill metadata and workflow instructions.
- `references/api-review-checklist.md`: supporting review checklist.

## Use
Install/import this skill into an Agent Skills-compatible host. Ask the agent to use `backend-developer` when implementing or reviewing backend work.

Review the skill before enabling it, especially before allowing any agent to run scripts or modify a database.
